# Life Sim Roadmap

This document outlines the planned technical improvements and feature additions for the 3D life simulation game.

## Planned Work (Estimated: 28+ Hours)

### 1. Multi-Story Building System (7 Hours)
- Add stairs placement and floor level transitions.
- Build floor cutaway toggles for multi-level buildings.
- Add second-floor foundation structural validation.

### 2. Weather & Environmental Cycles (6 Hours)
- Add rain, snow, and sunny weather particle effects using Three.js shaders.
- Implement temperature motives affecting outdoor comfort and moodlets.
- Add seasonal plant growth and exterior ground textures.

### 3. Community Lots & Travel (5 Hours)
- Build public community lot types (parks, gyms, and libraries).
- Add lot travel transitions and neighborhood loading state machines.
- Create automated townie generation for public gathering spots.

### 4. Expanded Careers & Active Tasks (5 Hours)
- Add culinary, athlete, and scientist career progression tracks.
- Build interactive daily job assignments required for promotions.
- Add work uniform clothing assets per career level.

### 5. Mobile Touch Controls & Audio Enhancements (5 Hours)
- Add touch gestures for pinch-to-zoom and multi-finger camera rotation.
- Implement adaptive virtual joystick for mobile character navigation.
- Add ambient soundscapes and positional 3D audio listeners.
